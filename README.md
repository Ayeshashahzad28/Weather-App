# 🌦 Weather App

A modern, real-time weather dashboard built using **HTML, CSS, and JavaScript** with API integration from **Open-Meteo**.  
It provides live weather updates, forecasts, sunrise/sunset tracking, and a responsive glassmorphism UI.

---

## 🚀 Features

- 🌍 Real-time weather data (Open-Meteo API)
- 🔄 Live auto-refresh system (5-minute updates)
- 📍 City-based weather search
- 🌡 Temperature (°C / °F toggle)
- 💧 Humidity tracking
- 💨 Wind speed display
- 🌅 Sunrise & 🌇 Sunset timing
- 📅 7-day weather forecast
- 📊 Temperature trend chart
- 🌙 Dark/Light theme toggle
- 📱 Fully responsive design
- ⚡ Smooth UI animations (glassmorphism)

---

## 🛠 Tech Stack

- HTML5  
- CSS3 (Glassmorphism UI)  
- JavaScript (Vanilla JS)  
- Open-Meteo API  

---

## 📡 API Used
